# Password Safety Checker

A browser-only learning tool that gives feedback about password length, character variety, common patterns, and repeated runs.

## Run

Open `index.html` in any modern browser. No install or build step is needed.

## What it demonstrates

- Semantic HTML, accessible controls, responsive CSS, and JavaScript event handling
- Client-side input handling and privacy-conscious design
- A transparent scoring heuristic and honest communication of limitations

## Limitations

This is not a password audit and does not check breached-password databases. Its score is a small teaching heuristic, not a true entropy calculation or proof of safety. Do not enter a real password. A password manager and unique passwords for every account are safer practices.

## Portfolio description

> Built a browser-only password feedback tool that evaluates length and predictable patterns without storing or transmitting user input. Designed an accessible interface and documented why a heuristic score cannot guarantee password security.
